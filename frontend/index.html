Доставка — интерфейс demo-сервиса

Эта папка зарезервирована под задачу FE-007 «Сверстать интерфейс demo-сервиса "Доставка"» (Никита Комаров).

Пока интерфейс не свёрстан, сервис доступен по адресу http://localhost:8090/ — там backend отдаёт простую страницу с данными из Vault и блоком синхронизации.

Контракты API, на которые опирается интерфейс, описаны в Swagger-документации Vault: /swagger/index.html (эндпоинты /services/consent, /services/data, /services/sync).
